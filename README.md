# Check API

API minimalist pentru lista de modele Chaturbate și sincronizarea statusului online cu Supabase.

## Configurare

Creează un fișier `.env` în root:

```env
SUPABASE_URL=https://qccspwftbbdslmbnysdc.supabase.co
SUPABASE_ANON_KEY=ey...
```

Apoi rulează:

```bash
yarn install
# sau
npm install
```

## Pornire

```bash
# watch mode
yarn start:dev
# sau
npm run start:dev

# build + prod
yarn build
yarn start:prod
```

Serverul pornește pe `http://localhost:3001`.

## Endpoinți

### `GET /model/cb`

Returnează lista modelelor de la Chaturbate API, filtrate doar pentru `current_show === 'public'`, mapate la `name` și `image_url`, cu paginare.

**Query:**

- `limit` — număr de rezultate pe pagină (default: `20`)
- `page` — pagina (default: `1`)

Exemplu: `GET /model/cb?limit=50&page=1`

**Răspuns:**

```json
[
  {
    "name": "bridgetjean",
    "image_url": "https://thumb.live.mmcdn.com/ri/bridgetjean.jpg"
  }
]
```

### `POST /model/cb`

Adaugă un model nou în tabelul `ChatModels`.

**Body:**

```json
{
  "name": "model_name",
  "status": "no_content"
}
```

`status` este opțional și poate fi: `no_content`, `love`, `reject`, `waiting`, `asap`.

**Răspuns:**

```json
{
  "ok": true
}
```

### `POST /model/cb/sync`

Sincronizează modelele din Supabase cu datele Chaturbate.

Pentru fiecare rând din `ChatModels`:
- verifică dacă este online la Chaturbate
- actualizează `isOnline`, `imageUrl` și `startedAt` în `ChatModels`

**Răspuns:**

```json
{
  "ok": true
}
```

## Structura tabelului Supabase

```sql
create table public."ChatModels" (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  name text null,
  "imageUrl" text null,
  "startedAt" timestamp with time zone null,
  "isOnline" boolean null,
  status modelStatus null,
  constraint ChatModels_pkey primary key (id)
);
```

Valori posibile pentru `status`: `no_content`, `love`, `reject`, `waiting`, `asap`.

## Arhitectura

- `src/supa-api.service.ts` — interacțiunea cu Supabase (`ChatModels`)
- `src/main.ts` — pornirea aplicației pe portul `3001`
